# Equipo 10 - Seguimiento de Prácticas Profesionales

## Descripción

Aplicacion web para el seguimiento de practicas profesionales de estudiantes en empresas colaboradoras, 
permitiendo registrar avances, actividades y evaluaciones de tutores academicos y empresariales.

## Tecnologías de la semana 1

- Java 11 o superior
- JSP y Servlets
- Apache Tomcat 9
- Apache NetBeans
- Maven

## Requisitos

1. JDK configurado.
2. Tomcat 9 registrado en el IDE.
3. Puerto del servidor disponible.

## Ejecución

1. Abrir el proyecto en NetBeans.
2. Limpiar y construir.
3. Ejecutar sobre Tomcat.
4. Abrir `http://localhost:8080/SistemaPasantias` en el navegador.
